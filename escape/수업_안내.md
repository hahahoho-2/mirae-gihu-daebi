# 2045 미래하우스 탈출 — 선생님용 안내

미래 의식주 생활 기술(스마트 팜, 대체 식품, 스마트 의류, 메타 패션, 3D 프린팅, 스마트 홈)을 탐구하는 **제한 시간 방탈출 RPG**예요.
기후 변화만 다루지 않고, 교과서의 네 가지 변화 요소(소비자 욕구·가족 구조·디지털 전환·환경 변화)를 함께 살피며 **필요 → 기술 → 비판적 수용**으로 생각하도록 만들었어요.

- **학생 배포 주소: https://hahahoho-2.github.io/mirae-gihu-daebi/escape/**
- 자동 시험: https://hahahoho-2.github.io/mirae-gihu-daebi/escape/tests/test.html
- (선생님 미리 보기용 시험판 `…/test/escape/`도 같은 내용이에요.)
- 폴더를 내려받았다면 `index.html`을 더블클릭해도 열려요(설치·서버 필요 없음).

## 한 판의 흐름 (7·10·15분 중 학생이 고름)
| 단계 | 장소 | 하는 일 | 교과서 |
|---|---|---|---|
| 1 | 🧭 안내실 | 장면 4개를 변화 요소 4가지로 나누기 | 23·31·37쪽 |
| 2 | 🍽️ 푸드 테크 키친 | 대체 식품 6개 분류(식물·곤충·배양육) → 스마트 팜 제어판(센서 값에 맞는 장치 켜기) | 24·27쪽 |
| 2 | 👕 스마트 드레스룸 | 스마트 의류 6벌 분류(안전·보안 / 건강 관리 / 상호 작용) → 고객 4명에게 맞는 의생활 기술 고르기 | 32~34쪽 |
| 2 | 🏠 스마트 홈 컨트롤룸 | 자동 기능 4개에 센서 연결 → 다중 인증(MFA) 도어록 만들기 | 38~39쪽, 스마트홈 작동 기술 자료 |
| 3 | 🚪 탈출 문 | 생각 바이러스 3마리(무조건 거부·무조건 믿음·기술 만능)를 근거 카드로 바로잡기 | 비판적 수용, 34·40쪽 |
| 4 | 📋 고객 의뢰 | 손님(할머니·맞벌이 가족·대학생 중 1명, 판마다 다름)에게 의·식·주 기술과 “꼭 확인할 점”을 고르기 | 종합 |

- 2단계의 세 방은 순서가 자유예요. 방마다 첫 자물쇠를 열어야 두 번째가 열리고, 두 번째를 열면 열쇠를 얻어요.
- 방의 ✨ 물건을 누르면 단서 카드(교과서 내용 요약)가 📒 수첩에 모여요. 퍼즐 창에도 관련 단서가 함께 보여요.

## 게임 장치 (집중과 흥미)
- **제한 시간**: 틀리면 10초가 줄어요. 시간이 다 되면 「연습 모드」로 시간 제한 없이 끝까지 풀 수 있어요(최고 기록에는 남지 않음).
- **미래 직업(RPG)**: 스마트 팜 구축가(교과서 29쪽 JOB담)·AI 패션 디자이너(교과서 33쪽 「AI 디자이너」)·스마트 홈 설계사(게임에서 만든 역할) 중 하나. 내 전문 방에서는 틀려도 시간이 줄지 않고, 그 방을 열면 코인 +15.
- **🛒 상점(게임 코인)**: 힌트 열쇠 20, AI 돋보기(정답 한 칸) 30, 실수 방패 15, 시간 충전 +60초 40(한 판 3번까지). 코인은 단서를 처음 볼 때 +5, 퍼즐을 풀 때 별 1개당 +5. 진짜 돈과는 관계없어요.
- **🎁 꾸미기 상점**: 판이 끝나면 남은 코인이 꾸미기 지갑으로 옮겨져요. 스마트 안경·헤드셋·워치·LED 모자·태양광 망토를 사서 캐릭터에 입혀요(이 기기에만 저장).
- **별·레벨**: 한 번에 풀면 별 3개, 한 번 틀리거나 힌트·돋보기를 쓰면 별 2개, 그 밖에는 별 1개. 11문제 최대 별 33개, 레벨 5(미래 생활 마스터).
- 점수 = 경험치(XP) + 남은 시간(초)÷10. 시간 안에 탈출했을 때만 매겨요.

## 수업에서 쓰는 예 (50분)
1. (5분) 교과서 22쪽 「생각 깨움」으로 미래 의식주 변화 이야기 → 게임 방법 안내
2. (10~15분) 게임: 처음에는 10분 모드를 권해요. 빠른 학생은 7분 도전 모드로 다시 하기.
3. (10분) 결과 화면 「📋 보고서 복사」 → 학급 게시판(클래스룸·패들렛)에 붙여 넣기. 보고서에는 풀이한 내용, 고객 설계, 학생이 쓴 “2045년 나의 의·식·주 상상”이 들어가요.
4. (15분) 토의: 같은 손님을 받은 학생끼리 모여 다른 선택지는 정말 틀렸는지, 기술의 한계는 무엇인지 이야기하기(비판적 수용).
5. (5분) 정리: 교과서 「배움 확인하기」

## 정답 요약 (선생님용)
- 안내실: 식물성 단백질(동물 복지) → 소비자 욕구 / 소포장·간편식 → 가족 구조 / AI 메뉴·서빙 로봇 → 디지털 전환 / 사막화·농지 감소 → 환경 변화
- 키친 분류: 콩고기·녹두 달걀 → 식물 / 갈색거저리 쿠키·쌍별귀뚜라미 단백질 바 → 곤충 / 줄기세포 고기·세포 배양 너겟 → 배양육
- 스마트 팜: 31℃ → 환기·냉방, 습도 40% → 가습, 빛 부족 → LED 생장등, 흙 마름 → 자동 물 주기
- 스마트 의류 분류: 등산복(GPS)·작업복(SOS) → 안전·보안 / 신발(걸음걸이)·운동복(심박) → 건강 관리 / 재킷(제스처)·사운드 셔츠 → 상호 작용
- 고객 맞춤: 등산가 → 스마트 등산복, 청각 장애 관객 → 사운드 셔츠, 직장인 → 가상 피팅, 발 모양이 특이한 학생 → 3D 프린팅 신발
- 센서: 밤 자동 조명 → 동작 감지(PIR), 가스 경보 → 가스, 블라인드·조명 → 조도, 공기청정기 → 미세먼지
- 다중 인증: 지식(비밀번호·보안 질문)·소유(등록된 스마트폰·스마트카드)·생체(특징)(지문·얼굴) 중 **서로 다른 종류 2가지**면 정답(예: 비밀번호+지문). 같은 종류 2개는 오답.
- 바이러스: 무조건 거부(곤충·배양육 거부) → 「곤충 단백질 식품」 또는 「대체 식품과 식물성 단백질」 / 무조건 믿음(가상 피팅 완벽) → 「메타 패션·가상 피팅」 / 기술 만능(3D 프린팅 집) → 「3D 프린팅 건축」. 「비판적 수용」 카드는 “좋은 태도지만 구체적 근거가 필요해요”라고 안내만 하고 감점하지 않아요.
- 고객 의뢰: 할머니 → 스마트 신발·맞춤 음식 추천 배달·동작 감지 조명과 건강 관리·간편식 나트륨 확인 / 맞벌이 가족 → GPS 안전 의류·스마트 냉장고와 간편 조리 세트·IoT 도어록 도착 알림·위치 정보 보안 / 대학생 → 가상 피팅과 7R·홈 파밍 저탄소 식단·에너지 관리 스마트 플러그·꼭 필요한 기기만 고르기

## 내용 근거와 선생님 확인이 필요한 부분
- 내용은 「기술·가정」 Ⅰ. 생활 문화와 디지털 환경 3~5단원(22~41쪽)과 「스마트홈 작동 기술」, 「3D 프린팅 건설 기술」 자료를 요약했어요.
- 온실가스 배출량 “쇠고기 59.6, 두부 3.0(단위: kgCO₂eq)”은 교과서 22쪽 그림(그린피스, 2020)의 숫자를 출처와 함께 그대로 옮겼어요. 교과서에 기준량(예: 1kg당)이 적혀 있지 않아 게임에서도 기준량을 덧붙이지 않았어요.
- 분류 문제의 「쌍별귀뚜라미 분말 단백질 바」, 「닭에게서 얻은 세포를 배양한 너겟」은 교과서의 식용 곤충 목록과 배양육 정의에 맞춘 예시 식품이에요.
- 스마트 팜의 설정값(24℃, 습도 60%)은 교과서 27쪽 그림을 참고한 예시예요. 게임에서는 “농부가 작물에 맞춰 정해 둔 설정값”이라고 밝혔어요(알맞은 값은 작물과 생육 단계에 따라 달라요).
- 통신 설명(Wi-Fi 빠르고 먼 거리, 블루투스 저전력 근거리, NFC 약 10cm 이내)과 센서·인증 분류는 「스마트홈 작동 기술」 자료를 따랐어요.
- 고객 의뢰의 정답은 “그 손님의 걱정을 가장 직접 해결하는 선택”이에요. 다른 선택지도 상황에 따라 쓸모가 있을 수 있으니 토의 거리로 써 주세요.

## 내용 점검 기록 (배포 전 재검토에서 고친 것)
| 항목 | 고치기 전 | 고친 뒤와 이유 |
|---|---|---|
| 배양육 | “살아 있는 동물 세포에서 얻은 줄기세포에 영양분을 공급해 실험실에서…”, “뼈대 제작” | 동물에게서 떼어 낸 세포(주로 줄기세포)를 **영양분과 성장 인자가 든 배양액**에서 키운다고 고쳤어요. ‘뼈대’는 뼈가 아니라 **지지체(세포가 붙어 자라는 틀)**라고 밝혔어요. 아직 생산 비용이 높고 판매 전 안전성 심사가 필요하다는 한계도 넣었어요. |
| 곤충 식품 | “고단백·저지방이고 무기질까지 풍부” | 지방 함량은 곤충 종류에 따라 크게 달라서(갈색거저리 유충은 지방이 적지 않음) “단백질과 무기질이 풍부한 식품으로 알려져 있다(영양 성분은 종류에 따라 다름)”로 고쳤어요. 갑각류 알레르기 주의도 넣었어요. |
| 스마트 팜 | “상추에 알맞은 환경(24℃)” | 상추는 서늘한 기후를 좋아하는 작물이라 24℃를 알맞은 온도라고 하기 어려워요. 특정 작물을 빼고 “농부가 정해 둔 설정값”으로 고쳤어요. |
| 인증 | “스마트폰 NFC(소유)”, “생체 기반(나 자신)” | NFC는 통신 방식이므로 “등록된 스마트폰(NFC)”으로, 자료의 용어에 맞춰 “생체(특징) 기반(내 몸의 특징)”으로 고쳤어요. |
| 센서 | “6대 스마트 센서” | 자료에는 소음 센서까지 7가지가 나와서 개수 표현을 빼고 소음 센서를 더했어요. 센싱 원리(물리적 변화 → 전기 신호 → 판단 → 자동 제어·알림)도 넣었어요. |
| 과일 섬유 | “과일 껍질로 만든” | 파인애플 잎처럼 껍질이 아닌 부산물로 만드는 경우도 있어 “과일 껍질 같은 과일 부산물”로 고쳤어요. 지속가능한 면화도 더했어요. |
| 저탄소 식단 | “식비도 아낄 수 있어요” | 확실하지 않은 효과라서 빼고, 생산·유통 과정의 탄소를 줄인다는 교과서 설명만 남겼어요. |
| 미래 직업 | “교과서 JOB담” | 스마트 홈 설계사는 교과서에 없는 게임 역할이라고 밝혔어요. |

## 저장과 개인정보
- 학생 기기의 브라우저에만 저장돼요(`yeoul-future-escape-v1`, 최고 기록 `yeoul-future-best-v1`, 꾸미기 지갑 `yeoul-future-closet-v1`). 서버로 보내는 정보는 없어요.

- 여울섬 기후 게임(상위 폴더)과 저장 칸이 달라서 서로 기록을 지우지 않아요.

## 내용 고치기
- `js/data.js`만 고치면 돼요: 시간(`GAME.modes`), 코인·상점 값, 방의 단서 글(`CLUES`), 퍼즐(`LOCKS`), 손님(`PERSONAS`), 바이러스(`MONSTERS`).
- 고친 뒤 `tests/test.html`을 웹 서버(또는 온라인 주소)로 열어 **실패 0**인지 확인해요. 정답이 하나뿐인지, 단서가 방에 있는지 등을 자동으로 검사해요.
